# API Futebol

A Spring Boot REST API for managing soccer matches, teams, and stadiums. This project is designed for CRUD operations and advanced queries related to football (soccer) statistics, rankings, and match retrospectives.

## Features

- Register, update, and delete teams (`clubes`), stadiums (`estadios`), and matches (`partidas`)
- List and filter matches, teams, and stadiums with pagination
- Retrieve rankings and historical matchups between teams
- Integration with ViaCEP for stadium address lookup by CEP

## Technologies

- Java 17+ / Spring Boot
- Maven
- Docker (optional)
- Lombok, JPA, Hibernate
- Postman collection for API requests
